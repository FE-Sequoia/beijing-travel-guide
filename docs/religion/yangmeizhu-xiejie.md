# 杨梅竹斜街

![杨梅竹斜街](https://images.unsplash.com/photo-1519501025264-65ba15a82390?w=1200)

> "一条斜街，半部民国书业史。"

## 简介

杨梅竹斜街位于北京市西城区大栅栏地区，东起煤市街，西至一尺大街，全长约496米。它是北京最有名的"斜街"之一，因清代曾聚集多家书局、书店而闻名，是民国时期北京的文化地标。如今经过更新改造，街区内既保留了老字号与传统风貌，又引入了众多设计工作室、文创店铺和特色咖啡馆，成为前门地区最有格调的慢游街区。

## 历史沿革

### 名字由来

杨梅竹斜街的名字始于明代，相传因胡同内种植杨梅树而得名。

### 书业一条街

清末民初，杨梅竹斜街聚集了商务印书馆、中华书局等众多书局与出版机构，是当时北京的出版文化中心，鲁迅、沈从文等文人常在此出入。

### 当代更新

2010年前后，大栅栏地区启动更新改造，设计师与艺术家入驻，老街焕发新生，成为"北京式慢生活"的样板街区。

## 街区特色

### 老字号与书店传统

街区内仍保留着济安斋、东昇平等老字号，也有许多主打设计类书籍的特色书店，延续着"书街"的文脉。

### 设计工作室与文创店

众多建筑师、设计师的工作室和原创品牌店隐匿其间，展览、装置艺术不时出现，边走边逛常有惊喜。

### 胡同咖啡馆

改造后的四合院与临街小屋变身为风格各异的咖啡馆、茶馆，适合歇脚闲聊。

## 游览攻略

### 推荐路线

**半日路线**：

杨梅竹斜街东口 → 老字号店铺 → 设计工作室 → 咖啡馆 → 西口一尺大街 → 琉璃厂

### 实用贴士

1. **搭配**：与琉璃厂文化街、前门大街、大栅栏连成一片，适合串联游览
2. **错峰**：游客较前门大街少，午后光影最佳
3. **拍照**：红砖墙、老招牌和民国风格的门脸是绝佳取景点
4. **注意**：街区内多为居民生活区，请保持安静、勿打扰住户

## 文化意义

杨梅竹斜街是北京旧城更新中"原住民共生"的代表案例。它没有大拆大建，而是在保留生活肌理的前提下引入新业态，让老街区既有烟火气，也有设计感。
