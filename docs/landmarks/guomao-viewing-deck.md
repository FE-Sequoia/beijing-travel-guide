# 国贸商城观景台

![国贸商城观景台](https://images.unsplash.com/photo-1611416457332-946853cc75d6?w=1200)

> "免费俯瞰央视大楼与CBD的隐藏阳台。"

## 简介

国贸商城观景台位于北京国贸商城北区6层的露天平台，是俯瞰北京CBD全景的免费观景地。站在平台上，可以近距离欣赏中央电视台总部大楼（"大裤衩"）、中信大厦（"中国尊"）以及国贸CBD鳞次栉比的摩天楼群，入夜后城市灯光亮起，车流如织、霓虹闪烁，是北京中心城区最经典的都市夜景机位之一。

## 观景特色

### 俯瞰央视大楼

观景台正对中央电视台总部大楼，是拍摄"大裤衩"的最佳免费机位之一，白天钢结构轮廓清晰，夜晚灯光亮起后更具视觉冲击力。

### 中国尊与CBD天际线

平台视野开阔，可同时收入中国尊、国贸三期等超高层建筑，向东望去整个CBD天际线尽收眼底。

### 都市夜景

入夜后国贸桥车流灯光如长河般流动，配合周边写字楼的窗灯与霓虹，构成北京最具代表性的现代都市夜景。

## 游览攻略

### 推荐路线

**夜景路线**：

国贸站E2口 → 国贸商城北区 → 一楼Nike对面电梯直达6层 → 观景台拍照 → 国贸商城晚餐

### 实用贴士

1. **交通**：地铁1/10号线国贸站E2口或F口出站，进入国贸商城
2. **上楼**：从一楼Nike专卖店对面的电梯上6层，即可到达露天观景台
3. **错峰**：观景台人气高，玻璃护栏较高，想避开人流建议傍晚蓝调时刻前到达
4. **拍摄**：日落前后到夜幕降临的蓝调时刻最出片，大厦熄灯后景色会打折扣
5. **搭配**：与国贸商城餐饮、三里屯、蓝色港湾等商圈串联游玩

### 交通方式

| 方式 | 路线 |
|:---|:---|

## 文化意义

国贸商城观景台是北京CBD夜间公共空间向市民开放的范例，让普通人无需消费即可在高处感受城市天际线的壮阔，也成为摄影爱好者与游客了解现代北京的重要窗口。
