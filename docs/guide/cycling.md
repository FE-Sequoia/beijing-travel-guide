# 北京骑行指南

> "老城不大，骑车刚刚好。"

## 为什么骑车

北京二环内的胡同片区步行走不完、坐车进不去，共享单车是最灵活的打开方式。骑行速度慢，恰好配合胡同的节奏：随时停下拍门墩、买糖葫芦、钻进小店。

## 经典路线一：胡同环线（约6公里，2-3小时）

**路线**：五道营胡同 → 雍和宫外墙 → 国子监街 → 钟鼓楼 → 什刹海 → 南锣鼓巷

- 五道营胡同：独立小店与咖啡馆，早上人少最好逛
- 国子监街：两侧槐树成荫，红墙配匾额，是北京最上镜的街巷之一
- 钟鼓楼：登不登楼都值得在楼下绕一圈
- 什刹海：银锭桥一带骑行需注意人流，傍晚看日落最佳

## 经典路线二：城南文化线（约8公里，3小时）

**路线**：前门大街 → 大栅栏 → 琉璃厂 → 杨梅竹斜街 → 东交民巷

- 前门大街：骑行主干道，两侧老字号
- 大栅栏/琉璃厂：街巷窄，建议推车慢逛，看老店铺与笔墨纸砚
- 杨梅竹斜街：最文艺的一段，安静、小店有格调
- 东交民巷：西洋建筑群，傍晚光线最好

## 进阶路线：首钢园（约10公里，半天）

首钢园园区开阔、路况好，工业遗存与冬奥场馆是绝佳骑行背景。地铁6号线或11号线可达，园内可租车，建议避开周末下午人流高峰。

## 骑行提示

- 共享单车在胡同片区投放充足，但早晚高峰可能难找，可步行至主街再扫车
- 什刹海、南锣鼓巷核心区周末人多，骑行请减速避让行人
- 北京夏季午后炎热，建议 17:00 后出发，还能衔接夜景
